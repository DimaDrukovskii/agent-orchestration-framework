# Голосовой агент для туризма на Дальнем Востоке

Алина — демонстрационный голосовой консультант по маршрутам Хабаровского края. Браузер записывает речь, сервер распознаёт её через Polza AI, получает потоковый ответ модели и озвучивает его через ElevenLabs. Диалог, заметки и карточки передачи менеджеру сохраняются в SQLite. Отдельный Hermes Agent развёрнут как экспериментальный профиль и не включён в голосовой путь по умолчанию из-за задержки.

**Статус:** закрытый стенд. Публичный HTTPS, подключение телефонного номера, бронирование, подтверждение мест и оплата пока отсутствуют. Заявления о времени ответа менее секунды и о коммерческой готовности не подтверждены измерениями.

## Каталог

`tenants/far_east_travel/catalog.json` содержит проверенные публичные предложения сторонних организаторов. При первом поиске они загружаются в таблицу `market_tours` SQLite. Для каждой записи сохранены цена в рублях, организатор, источник и дата проверки. Это рыночные ориентиры, **не предложения нашей компании**. Даты, наличие мест и итоговую стоимость уточняет организатор. Дополнительная справка находится в `tenants/far_east_travel/knowledge/`.

Чтобы добавить собственные туры, нужны подтверждённые цены, календарь выездов, вместимость, состав услуги, правила отмены и источник обновления. Одного текстового файла для приёма бронирований недостаточно.

## Запуск локально

Создайте `.env` с `TENANT=far_east_travel`, `LLM_PROVIDER=polza`, `POLZA_API_KEY`, `POLZA_MODEL`, `TTS_PROVIDER=elevenlabs`, `TTS_API_KEY` и `TTS_VOICE_ID`. Секреты остаются в `.env`, который исключён из Git.

```bash
uv venv --python python3.11 .venv
uv pip install --python .venv/bin/python -r requirements.txt
bash scripts/voice_chat_polza.sh
```

Откройте `http://127.0.0.1:8000/demo/call.html` в браузере с доступом к микрофону. Для ручной проверки готовности: `/health` и `/ready`. Тесты: `.venv/bin/pytest -q tests`.

## Облачный стенд

Порядок развёртывания и ограничения безопасности описаны в [docs/CLOUD_STAGING.md](docs/CLOUD_STAGING.md). Приложение слушает только `127.0.0.1:8000` сервера и открывается через SSH-туннель. Отдельный контейнер Hermes имеет свой том данных и не использует личный экземпляр Hermes на том же сервере. Подписка Nous для API-модели не требуется.

## Структура

| Путь | Назначение |
| --- | --- |
| `src/agent/` | диалоговый цикл, инструменты, поиск справки |
| `src/services/` | сессии, каталог, распознавание, озвучка, аналитика |
| `src/api/` | HTTP-маршруты приложения |
| `src/telephony/` | телефонный адаптер; на облачном стенде выключен |
| `tenants/far_east_travel/` | персона, маршруты и каталог текущего профиля |
| `demo/` | браузерный голосовой интерфейс и служебные страницы |
| `docker/` | контейнеры приложения, Redis и отдельного Hermes |
| `tests/` | локальные тесты без платных API-вызовов |

`tenants/mts/` и `docs/mts/` сохранены как исторические материалы прежнего прототипа; текущий туристический профиль их не загружает. `tenants/climateplus/` и `docs/COURSE_DEMO.md` относятся к прежней демонстрации и также не используются облачным стендом.
