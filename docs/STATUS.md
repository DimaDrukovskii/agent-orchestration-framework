# Проверенный статус продукта

Обновлено 21 ноября 2026. Это журнал проверок, а не обещание готовности к коммерческой эксплуатации.

## Проверено

- Короткая русская фраза успешно озвучена ElevenLabs голосом Marina (`ymDCYd8puC7gYjxIamPt`) через API в MP3 и в телефонном формате µ-law 8 кГц. Локальный ключ хранится только в `.env`.
- 218 локальных автоматических тестов прошли с заполненным `.env`; тесты подменяют платных провайдеров заглушками.
- Текстовый симулятор создаёт заявку, хранит историю, классифицирует её и продолжает разговор после имитации обратного звонка.
- При закрытии телефонной сессии профиль «КлиматПлюс» сохраняет транскрипт и одну карточку с консервативной квалификацией. Тест покрывает повторное завершение и перевод.
- Путь «симулятор → Hermes → MCP календаря → SQLite» проверен с локальной сценарной моделью. Свободный диалог с облачной моделью ещё не измерен.

## Что делают инструменты

| Компонент | Действие | Граница проверки |
| --- | --- | --- |
| `search_knowledge_base` | Ищет сведения о компании в Markdown-файлах профиля. | Ответ зависит от актуальности базы знаний. |
| `save_handoff_card` | Собирает имя, потребность, бюджет, срок, телефон и комментарий. Диалог записывает карточку в хранилище после завершения хода. | Внешний Hermes сейчас не получает этот инструмент напрямую. |
| `available_slots` / `create_request` через MCP | Читают свободные окна и создают заявку в SQLite. ID запроса защищает от повтора. | Это демонстрационный календарь, не рабочая CRM компании. |
| `transfer_to_department` | Запрашивает перевод звонка на номер отдела. Транспорт выполняет перевод. | Успех зависит от настройки АТС и должен проверяться на реальной линии. |
| `finalize_call` | На завершении телефонного звонка фиксирует транскрипт, категорию и карточку. | Распознаёт только явно произнесённые факты; качество на реальных звонках ещё не измерено. |
| Очередь callback | Хранит задание и повторы в SQLite. | Сейчас подключён только симулятор исходящего вызова. |

## До первого клиента

1. Выбрать модель с поддержкой инструментов и проверить её на живых русских разговорах.
2. Подключить распознавание речи, проверить имена, числа, адреса и задержку от конца реплики до ответа.
3. Получить параметры SIP/АТС оператора и пройти входящие, исходящие, перевод и сбои на реальном номере.
4. Заменить демонстрационный календарь и базу знаний данными компании; добавить подтверждённый канал уведомления менеджера.
5. Измерить точность квалификации, долю успешно завершённых звонков, задержки p50/p95 и восстановление после перезапуска.
6. Ограничить доступ к публичному виджету и управленческим API, определить резервный маршрут и мониторинг.
