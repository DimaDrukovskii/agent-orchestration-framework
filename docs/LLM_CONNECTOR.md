## Что имеется в виду под «Hermes»

В проекте «Hermes» — имя нашего агента (ReAct-цикл + инструменты), он не зависит от модели.
Отдельно существуют открытые модели Hermes (Nous Research, веса публичные). Их можно
поднять на своём железе или у хостера и поставить «мозгом» нашего агента.
Это ответ и на вопрос локализации данных (`docs/PITCH_COMPLIANCE.md`, п.1).

## Структура (по паттерну `tts_provider`)

```
LLM_PROVIDER = anthropic | openai_compat      # дефолт: anthropic
LLM_BASE_URL = http://localhost:8001/v1       # для openai_compat (vLLM, Ollama, облако РФ)
LLM_API_KEY  = ...                            # токен провайдера, в .env
LLM_MODEL    = <имя модели у провайдера>      # сейчас ANTHROPIC_MODEL
```

- `src/services/llm_client.py` — единый метод `complete(system, messages, tools)`.
  Возвращает наш внутренний вид: текст + список вызовов инструментов.
- Реализации: `AnthropicClient` (то, что есть сейчас) и `OpenAICompatClient`.
  Один OpenAI-совместимый клиент закрывает vLLM/Ollama с Hermes и, вероятно,
  часть российских облаков (совместимость каждого проверять отдельно, не предполагать).
- `hermes_agent.py` перестаёт знать про Anthropic и работает только с `complete()`.

## Что придётся переписать

Это не одна строка в конфиге:
1. **Формат инструментов.** У нас схемы и `tool_use`/`tool_result` в формате Anthropic.
   У OpenAI-совместимых API другой формат (`tool_calls`, роль `tool`). Нужен переводчик в обе стороны.
2. **История в Redis/SQLite** хранит блоки Anthropic. Нужен нейтральный формат, иначе сессии не переживут смену модели.
3. **Качество tool calling у открытых моделей ниже.** Нужно заново прогнать сценарии
   (`scripts/test_call.py`, таблица фраз): перевод, поиск по базе, вежливость, отсутствие «я ИИ»-проговорок.
4. **Русский язык, задержка и стоимость железа** (GPU) надо мерить, а не верить карточке модели.
5. **Стриминг** (`run_streaming`) — второй формат, переводить отдельно.

## Порядок, когда дойдём

1. Нейтральный формат сообщений + `llm_client.py`, Anthropic остаётся дефолтом (тесты зелёные).
2. `OpenAICompatClient`, проверка на локальной Ollama/vLLM с Hermes.
3. Прогон сценариев на обеих моделях, сравнение в `docs/DEMO_RESULTS.md`.
4. Только потом российские провайдеры (`docs/VOICE_PIPELINE_RU.md`).
