# Телефония: позвонить на номер и поговорить с агентом (Twilio)

Звонок на номер Twilio попадает на наш сервер, дальше то же ядро диалога, что и у виджета: база знаний клиента,
инструменты, перевод на человека, запись звонка, аналитика расходов.

```
телефон ─▶ Twilio ─▶ POST /telephony/twilio/voice (проверка подписи) ─▶ TwiML <Connect><Stream>
                  ╰▶ WS /telephony/twilio/stream   µ-law 8 кГц, кадры по 20 мс, в обе стороны
                       │ src/telephony/session.py
                       ├─ EndpointDetector: когда абонент начал и договорил
                       ├─ /api/stt (gpt-4o-transcribe)  ─▶ src/services/dialog.py run_turn ─▶ озвучка (Polza) ─▶ µ-law
                       └─ абонент перебил: clear, озвучка обрывается; молчит: «Вы меня слышите?», прощание
```

## Что нужно от вас (я не могу это сделать за вас)

1. Аккаунт Twilio и номер с голосовой связью. Доступность номеров нужной страны (в том числе Беларуси) проверьте в консоли Twilio:
   для первой проверки подойдёт номер любой доступной страны.
2. Публичный HTTPS-адрес сервера. Локально: `ngrok http 8000` или `cloudflared tunnel --url http://localhost:8000`. Twilio подключается к потоку только по `wss`.
3. Переменные в `.env` (имена в [ENVIRONMENT.md](ENVIRONMENT.md)):

```
TELEPHONY_ENABLED=true
PUBLIC_BASE_URL=https://ваш-адрес          # без слэша в конце, тот же, что в консоли Twilio
TWILIO_AUTH_TOKEN=...                       # подпись вебхука и защита потока
TWILIO_ACCOUNT_SID=...                      # нужен только для перевода звонка на человека
TTS_PROVIDER=polza  TTS_VOICE_ID=...        # голос; POLZA_API_KEY, POLZA_MODEL=anthropic/claude-haiku-5.5
```

4. Консоль Twilio: Phone Numbers → ваш номер → Voice Configuration → «A call comes in»: Webhook, метод `POST`, адрес
   `https://ваш-адрес/telephony/twilio/voice`.
5. `docker compose --env-file .env -f docker/docker-compose.yml up -d`, затем позвоните на номер. В журнале: `call start`, `call end`.

## Как звучит разговор: на что это похоже

| Ситуация | Что делает агент |
|---|---|
| Абонент договорил | ответ начинается с первой готовой фразы, не дожидаясь конца ответа модели (потоковый ответ) |
| Модель или инструмент думают дольше 1,2 с | сам говорит «Угу, секунду.», «Так, смотрю.» (`fillers`, `TELEPHONY_FILLER_AFTER_MS`); если и через 3 с тихо, «Ещё секунду, уточняю.» (`long_fillers`) |
| Модель молчит дольше 20 с | извиняется и просит повторить (`TELEPHONY_TURN_TIMEOUT_SECONDS`) |
| Разговор дольше окна истории (12 сообщений) | факты о звонке (имя, семья, даты) дописываются в фоне в короткие заметки и подставляются в каждую реплику (`src/services/dialog.py`, `update_notes`) |
| Абонент перебил | озвучка обрывается; в истории остаётся только услышанное с пометкой `[абонент перебил]`, и агент отвечает на вставку, а не повторяет всё |
| Абонент добавил или уточнил, пока агент думал | недоделанный ответ отменяется, реплики склеиваются, агент отвечает на всё сразу |
| Нужен инструмент | сначала говорит короткую фразу («секунду, смотрю»), потом вызывает его |

Не сделано: короткие поддакивания («угу») пока абонент говорит, и предсказание конца фразы до паузы.

## Что настраивается под клиента: `tenants/<имя>/telephony.json`

Приветствие (оно называет ИИ), фразы для молчания, ошибки, прощания и **номера для перевода на человека**:
`{"transfer_numbers": {"биллинг": "+375...", "default": "+375..."}}`. Отдел берётся из вызова агента `transfer_to_department`.
Нет номера: агент говорит, что передал вопрос специалисту, и кладёт трубку (Telegram-уведомление остаётся). Перевод требует `TWILIO_ACCOUNT_SID`.

## Защита и ограничения расходов

- Вебхук принимает только запросы с верной подписью Twilio (`X-Twilio-Signature`), иначе 403. Поток принимает только соединения с токеном, выданным вебхуком.
- `TELEPHONY_MAX_CONCURRENT_CALLS` (100): сверх лимита абонент слышит «линии заняты». `TELEPHONY_MAX_CALL_SECONDS` (1200): потолок длины звонка.
- Молчание: через 12 с «Вы меня слышите?», через 30 с прощание (`TELEPHONY_IDLE_*`).
- Три ошибки диалога подряд: извинение и конец звонка. Сбой озвучки пишется в журнал, звонок не падает.
- `TWILIO_VALIDATE_SIGNATURE=false` только для локальной отладки, на сервере держать включённым.

## Что проверено и что нет

Проверено автоматически на имитации потока Twilio (`tests/test_telephony.py`, без сети): кодек G.711, определение конца реплики,
подпись вебхука, отказ без токена, полный разговор (приветствие, реплика, ответ), перебивание агента, перевод и отказ при отсутствии номера,
сборка Docker-образа. Нагрузка слоя (`scripts/load_test_phone.py`, 150 одновременных звонков, модель имитируется): запас по процессору в несколько раз.

**Не проверено:** реальный звонок. Задержка ответа (пауза после слов абонента: распознавание + модель + озвучка), качество распознавания
узкополосного телефонного звука (8 кГц) и поведение на реальной линии известны только после первого звонка. Измерьте их на нём; цена Twilio за минуту
в панель аналитики не входит (там только наши расходы на модель, озвучку и распознавание).

## Как добавить другого провайдера (SIP, Exolve и т. д.)

Логика звонка (`src/telephony/session.py`) не знает про Twilio: ей нужны колбэки отправки звука, `clear`, завершения и перевода (`Pipeline`).
Новый провайдер это ещё один файл рядом с `src/telephony/routes.py`: принять входящий звук, перевести его в µ-law 8 кГц и собрать `Pipeline`.
