# Открытые вопросы комплаенса (слайд питча)

Из `docs/mts/TRACK1_PLAN.md`, раздел «Открытые вопросы комплаенса» — говорим на
питче, не прячем.

1. **Локализация данных.** Claude API и Supabase — зарубежные облака; в проде
   нужен либо локальный контур, либо юридическая оценка конкретного провайдера.
   Конкретный путь — замена на российские провайдеры (YandexGPT/GigaChat,
   Yandex SpeechKit, MTS Exolve) см. `docs/website_side_bar/VOICE_PIPELINE_RU.md`.
2. **Согласие на запись/обработку ИИ.** Звонящий должен быть уведомлён, что
   разговор обрабатывает ИИ — в MVP не реализовано.
3. **Согласие бизнеса-абонента на сервис.** Подключение агента к звонкам
   подразумевается API-ключом, явного согласия не формализовано.
4. **Тайна связи и аудит.** Нужен лог «кто/когда/зачем обращался к записи или
   расшифровке» — не реализовано.
5. **Масштаб и SLA.** Прод рассчитан на сотни тысяч абонентов и ~99.9%
   доступности — прототип этого не показывает, архитектура масштабирования
   описана отдельно в `docs/mts/SCALING_PLAN.md`.
