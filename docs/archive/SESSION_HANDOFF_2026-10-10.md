```
Chrome (микрофон, Web Speech API, распознавание идёт через Google)
```

- Виджет: `demo/call.html`, правый нижний угол, светлая карточка в стиле ElevenLabs (дизайн утверждён владельцем, не менять). Настройки (шестерёнка): модель агента (Облако / Hermes Agent / Локальная), резервный голос браузера, ключ `X-API-Key`.

Прочее с дефолтами в `src/config.py`: `LLM_MAX_TOKENS=300`, `LLM_MAX_HISTORY_MESSAGES=12`, `LLM_PROMPT_CACHE=true`, `LLM_KB_PRERETRIEVAL=true`, `LLM_MAX_TURNS=20`, `LLM_REASONING_EFFORT=none`. Полный список: `docs/website_side_bar/ENVIRONMENT.md`.

**Важно:** compose ищет `.env` рядом с `docker/`, а не в корне. Запускать всегда так:
```bash
docker compose --env-file .env -f docker/docker-compose.yml up -d
```
Ассистенту доступ к `.env` и `.env.example` закрыт настройками; значения ключей в чат присылать не нужно.

## 5. Hermes Agent (Nous Research)

- Образ собран из `docker/hermes/` (установщик закреплён по sha256, код по коммиту `dce1e9b`, не от root, порт только на localhost). Сервис `hermes` в `docker/docker-compose.yml`.
- Уроки: API-сервер включается **только при `API_SERVER_KEY` ≥ 16 символов** (иначе молча «No messaging platforms enabled»); запуск `hermes gateway run`; у этой версии нет провайдера `polza`, нужен `provider: custom` + `base_url` + `api_key`; без `context_length` Hermes считает окно слишком малым.
- Статус: `/health` 200, `/v1/models` показывает `hermes-agent`, цепочка «виджет → наш API → Hermes → Polza» соединена. **Живой ответ модели через Hermes не получен** (упирался в лимит Polza).
- Ограничения: наши инструменты (база знаний, перевод на отдел) Hermes через API **не вызывает**; для этого нужен отдельный шаг (наши инструменты как MCP-сервер, подключённый к Hermes). Он дороже: резерв 10,98 ₽ на запрос против 1,0–1,7 ₽ у нашего агента. Рекомендация ассистента: в боевую цепочку звонка не ставить; оставить режимом в виджете.

## 6. Принцип телефонии и где стоит ИИ

Звонок это двусторонний аудиопоток в реальном времени, который поднимается по сигнализации.
1. Телефон → сеть оператора (GSM/ТфОП) → шлюз/SBC превращает в IP.
2. Сигнализация SIP (INVITE, 180 Ringing, 200 OK, BYE, REFER для перевода) устанавливает вызов; сам звук идёт по RTP (G.711 8 кГц у телефонии, Opus 16+ кГц в WebRTC), пакетами по 20 мс.
3. ИИ-агент это «абонент на том конце»: он принимает вызов как оператор, получает входящий аудиопоток (Twilio Media Streams: WebSocket, base64, 8 кГц μ-law), распознаёт, думает, озвучивает и отправляет аудио обратно. Перевод на человека это SIP-перевод вызова в очередь оператора.
4. Бюджет задержки для живого разговора: первый звук ≤ 1–1,5 с; перебивание (агент замолкает, когда абонент заговорил).

Целевая структура: `микрофон/телефон → [детектор речи → потоковое распознавание → LLM потоком → резка на предложения → потоковая озвучка] → аудио назад`, поверх «мозг агента» (промпт, база знаний, инструменты, перевод) и метрики (цена звонка, задержка, доля переводов). Готовые каркасы: Pipecat, LiveKit Agents (не пробовались здесь).

## 7. Человечность речи: рычаги (приоритет №1)

1. **Голос:** сравнить на слух ElevenLabs (Sarah, Rachel, Aria; модели `multilingual-v2`, `eleven-v4`) и Google TTS; голос выбирать ушами, а не по прайсу.
2. **Задержка:** потоковая выдача по предложениям (первый звук сейчас 4–6 с, цель ≤ 1,5 с).
3. **Перебивание и паузы:** агент замолкает, когда абонент заговорил; «секунду…» при долгом инструменте.
4. **Текст для озвучки:** короткие фразы, без списков и markdown, числа и аббревиатуры («МТС», суммы, телефоны) нормализовать до озвучки.
5. **Тон:** `stability` ниже = эмоциональнее (`TTS_STABILITY=0.45`), у `gpt-4o-mini-tts` есть параметр `instructions` (тон речи).
6. **Промпт:** живые вставки («так, смотрите», «ага»), не повторять вопросы абонента (в тестах Алина дважды спрашивала одно и то же; промпт поправлен, не проверено).

## 10. Правила работы, закреплённые в сессии

- **Не запускать платные запросы к LLM/TTS без явной команды владельца.** Часть расхода дня (около 48 ₽ по ключу) вызвали тесты ассистента на Sonnet 4.
- Диагностика расхода бесплатна: `GET /key`, `GET /history/generations`, `GET /models` у Polza. Скрипты — из контейнера (`docker exec docker-app-1 python …`), ключ не печатать.
- Не писать значения ключей в чат и в файлы; на скриншотах `.env` замазывать значения.
