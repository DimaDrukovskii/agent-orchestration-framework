# Стенд «КлиматПлюс»

Для запуска нужен Python 3.11 и установленные зависимости. При установке
пакетов может потребоваться интернет. Сам сценарий работает локально.

```bash
python3.11 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
TENANT=climateplus CALLBACK_SIMULATOR_ENABLED=true CALLBACK_START_HOUR=0 \
  CALLBACK_END_HOUR=24 uvicorn src.main:app --host 127.0.0.1 --port 8000
```

Откройте [симулятор](http://127.0.0.1:8000/demo/phone.html). Для чистого
локального запуска поле ключа уже заполнено тестовым значением.

1. Нажмите «Входящий звонок». Скажите «Нужен монтаж кондиционера. Сколько стоит?»
2. Поставьте флажок «Перебить ответ». Скажите «А если дождь? Бюджет 600 BYN».
3. Скажите «Поправка: бюджет 800, нужно через 3 дня. Я сам согласую.
   Соедините с менеджером».
4. В карточке появятся категория HOT, бюджет 800 BYN, срок 3 дня и
   следующий шаг. Нажмите «Назначить обратный звонок».
5. Дождитесь статуса «Абонент ответил» и нажмите «Поднять трубку».
   Новый звонок ссылается на исходный и сохраняет уточнённый бюджет и сроки.

Стенд принимает текстовые реплики. Перебивание отмечает, какая часть
предыдущего ответа была услышана. Выделение полей использует
детерминированный тестовый адаптер с правилами из профиля компании.
Ответы о цене и условиях берутся из демонстрационной базы знаний.
Телефонное соединение и синтез речи на этом стенде имитируются.

## Будущая приёмка на линии +375

| Сценарий | Что проверить |
| --- | --- |
| Входящий звонок | Номер абонента передан в систему. Звук слышен с обеих сторон. |
| Качество речи ElevenLabs | На телефоне разборчивы названия, цены, даты и адреса. При перебивании озвучка останавливается, а следующий ответ учитывает поправку. |
| Задержка | На серии звонков измерить от конца речи до первого содержательного аудио. Записать размер выборки, p50 и p95. |
| Исходящий вызов | Согласованный номер +375 отображается у получателя. При занятости и отсутствии ответа сохраняется статус, повтор соблюдает часы дозвона. |
| Перевод | При просьбе о человеке звонок доходит до сотрудника, который видит карточку. |
| Сбой | Отключить сервер агента на тестовой линии и убедиться, что оператор направляет звонок по согласованному резервному маршруту. После восстановления повтор задания не создаёт лишний вызов. |

### Настройки аудиоканала для будущей линии

Для ElevenLabs задайте `TTS_PROVIDER=elevenlabs`, `TTS_API_KEY`,
`TTS_VOICE_ID` и, при необходимости, `TTS_MODEL=eleven_flash_v2_5`.
Телефонный адаптер принимает поток G.711 μ-law 8 кГц и начинает
воспроизведение сразу после получения аудио. Тест инъецирует локальный
поток и проверяет закрытие потока и очистку буфера при перебивании.

В `telephony.json` можно указать `fallback_number`. Приложение
попробует этот номер, если основной перевод завершился ошибкой, или
после трёх ошибок диалога подряд. Маршрут на случай остановки всего
сервера настраивается на стороне АТС и проверяется отдельно.

### Свободные окна и заявка

В симуляторе после описания услуги спросите «Есть свободные окна?».
Выберите предложенное время и отправьте «Запишите на» с точным значением
слота. Заявка сохранится в SQLite, а время визита появится в карточке
менеджера. Календарь задаётся в `tenants/climateplus/appointments.json`.

Для профиля `hermes_agent` настройки сервера MCP лежат в
`docker/hermes/appointments.yaml`. Профиль Compose `hermes` запускает
MCP-процесс по stdio и хранит его заявки в томе `hermes_data`.
В учебной конфигурации API Hermes получает инструменты только из этого MCP-сервера. Для
подстановки своего сервера можно примонтировать другую конфигурацию и
указать её путь в `HERMES_MCP_CONFIG`, либо задать пустое значение для
отключения. У этого профиля свой демонстрационный календарь. Запуск
Hermes с облачной моделью требует настройки модели и её ключа.

### Подключение Asterisk

Точка подключения медиа находится по адресу `/telephony/asterisk/media`.
Для неё нужен Asterisk с JSON-командами `chan_websocket` (например, 22.8+).
Задайте приложению `ASTERISK_MEDIA_PASSWORD`. На стороне АТС создайте
исходящее WebSocket-соединение с пользователем `asterisk` и тем же паролем.
Используйте закрытую сеть или WSS. Для локальной отладки допустим WS.

```ini
; websocket_client.conf
[voice_agent]
type = websocket_client
connection_type = per_call_config
uri = wss://voice.internal.example/telephony/asterisk/media
protocols = media
username = asterisk
password = CHANGE_BEFORE_USE
tls_enabled = yes
verify_server_cert = yes
verify_server_hostname = yes
```

Для проверки только медиа можно вызвать
`Dial(WebSocket/voice_agent/c(ulaw)f(json))` из тестового контекста АТС.
Для рабочего перевода контроллер ARI должен передать в переменных
медиаканала `AGENT_CALLER_NUMBER` и `AGENT_CALLER_CHANNEL` (ID канала
абонента в Stasis). Приложение вызывает `channels/{id}/continue` с
номером перевода как добавочным в заданном контексте. Настройте
`ASTERISK_ARI_URL` с суффиксом `/ari`, `ASTERISK_ARI_USERNAME`,
`ASTERISK_ARI_PASSWORD` и `ASTERISK_TRANSFER_CONTEXT`. Контекст АТС
должен явно разрешать номера назначения.

Публичный номер, SIP-транк, ARI-контроллер для активных вызовов и
операторский резервный маршрут настраиваются при подключении линии.
Локальный тест прогоняет входящий формат WebSocket, аудио и перебивание
с тестовыми адаптерами. Для исходящих пока используется симулятор.

[Протокол chan_websocket](https://docs.asterisk.org/Configuration/Channel-Drivers/WebSocket/)

Чтобы использовать Hermes в том же интерфейсе симулятора, задайте
`SIMULATOR_USE_HERMES=true` и запустите профиль Compose `hermes` с
настроенным шлюзом модели. Симулятор передаст Hermes историю реплик с
пометками перебивания и поля предыдущего разговора при обратном звонке.
Учебная квалификация по-прежнему рассчитывается по правилам профиля.
Для демонстрации без ключей оставьте `SIMULATOR_USE_HERMES=false`.

Для проверки других исходов задайте `CALLBACK_SIMULATOR_OUTCOME=busy`
(линия занята) или `CALLBACK_SIMULATOR_OUTCOME=no_answer` (нет ответа).
Можно сократить `CALLBACK_RETRY_SECONDS` и задать
`CALLBACK_MAX_ATTEMPTS=2`, чтобы увидеть повтор и окончательный статус.

Для проверки Hermes без облачного ключа укажите адрес локального
OpenAI-совместимого сервера в `HERMES_MODEL_BASE_URL` и имя доступной
модели в `HERMES_MODEL`. Для вызова инструментов нужна модель с
поддержкой tool calling. `HERMES_MODEL_API_KEY` задаётся, если локальный
шлюз требует авторизацию.

### Постоянный стенд

Для круглосуточного стенда запустите Docker на сервере с автозапуском
самого Docker после перезагрузки. Из корня репозитория поднимите профиль:

```bash
docker compose -f docker/docker-compose.yml up -d --build app
docker compose -f docker/docker-compose.yml ps
curl -fsS http://127.0.0.1:8000/health
```

Перед открытием доступа извне настройте HTTPS и задайте собственный
`AGENT_API_KEY` через окружение Compose. Сохраняйте каталог `data/` при
обновлении сборки: в нём SQLite с карточками, разговором и заданиями
обратного звонка. Для проверочного стенда включите
`CALLBACK_SIMULATOR_ENABLED=true`. Политика `unless-stopped`
перезапускает приложение при выходе процесса. `GET /health` возвращает
503, если включённый обработчик очереди завершился.

Если диалог ведёт отдельный Hermes, запустите также
`docker compose -f docker/docker-compose.yml --profile hermes up -d --build hermes`.
Hermes имеет собственную проверку `/health` и ту же политику автоперезапуска.
При локальной модели приведите `HERMES_CONTEXT_LENGTH` в соответствие с
контекстом, выделенным сервером модели. Закреплённая версия Hermes требует
минимум 64 000 токенов. Для Ollama можно задать
`OLLAMA_CONTEXT_LENGTH=64000` на сервере модели и
`HERMES_CONTEXT_LENGTH=64000` в Compose. Для диагностики используйте
`docker compose -f docker/docker-compose.yml --profile hermes logs hermes`.

### Результат проверки учебного этапа

Проверен чистый образ приложения с одним профилем «КлиматПлюс». В нём
входящий вызов сформировал карточку, назначенный обратный звонок сохранил
контекст, а повтор команды менеджера вернул то же задание.

Отдельно в одном сеансе проверена цепочка «симулятор → контейнер Hermes →
локальный тестовый адаптер модели → оба MCP-инструмента → SQLite».
Запись о визите появилась в базе Hermes, карточка получила итог
квалификации, а обратный вызов вернул данные исходного обращения.
Тестовый адаптер отвечает по сценарию. Для оценки свободного диалога
подключите модель с поддержкой инструментов и контекстом от 64 000
токенов. У проверенного тега `qwen2.5:3b` Ollama ограничил
фактическое окно 32 768 токенами даже при большем запрошенном значении.

### Пилот с OpenRouter и ElevenLabs

Для пилота модель, синтез и распознавание настраиваются отдельно.
Задайте значения в локальном `.env` или в хранилище секретов сервера.

```dotenv
HERMES_MODEL_BASE_URL=https://openrouter.ai/api/v1
HERMES_MODEL=<идентификатор модели OpenRouter>
OPENROUTER_API_KEY=<ключ OpenRouter>
HERMES_CONTEXT_LENGTH=<окно контекста модели, минимум 64000>
HERMES_API_KEY=<секрет между приложением и шлюзом Hermes>
AGENT_API_KEY=<секрет доступа к API приложения>
TELEPHONY_MODEL_PROFILE=hermes_agent
TTS_PROVIDER=elevenlabs
TTS_API_KEY=<ключ ElevenLabs>
TTS_VOICE_ID=<идентификатор голоса ElevenLabs>
TTS_MODEL=eleven_flash_v2_5
POLZA_API_KEY=<ключ распознавания речи>
```

Выберите в OpenRouter модель с поддержкой вызова инструментов. Ключ
OpenRouter передаётся контейнеру Hermes. Ключи ElevenLabs и STT нужны
приложению. Текущая реализация распознавания использует Polza.

```bash
docker compose --env-file .env -f docker/docker-compose.yml --profile hermes up -d --build
docker compose --env-file .env -f docker/docker-compose.yml --profile hermes ps
curl -fsS http://127.0.0.1:8000/health
curl -fsS http://127.0.0.1:8642/health
```

`/health` подтверждает доступность локального процесса. До включения
клиентского трафика пройдите сценарии приёмки на тестовой линии. Проверьте
вызов обоих MCP-инструментов на выбранной модели, реакцию на таймауты
и исчерпание квоты каждого провайдера, перевод на резервный номер и
восстановление после перезапуска. Реальный исходящий дозвон через
оператора требует подключения SIP и проверки его ответов. Текущая
очередь исходящих проверена с симулятором.
